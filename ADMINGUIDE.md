# Admin Guide & Setup

## 1. Supabase Setup

To enable the backend features (Vault, Guestbook, Portal, Profile, Playlist), you need a Supabase project.

1.  **Create a Project:** Go to [database.new](https://database.new) and create a new project.
2.  **Get Credentials:** Go to **Project Settings > API**.
    *   Copy the `Project URL`.
    *   Copy the `anon` `public` key.
3.  **Update Environment:**
    *   Open the `.env` file in the root directory.
    *   Paste your URL and Key:
        ```env
        PUBLIC_SUPABASE_URL=your-project-url
        PUBLIC_SUPABASE_ANON_KEY=your-anon-key
        ```

## 2. Database Schema (New V2)

Run the content of `supabase_upgrade.sql` in the **SQL Editor** of your Supabase dashboard.

Alternatively, copy and run this:

```sql
-- 1. Upgrade 'works' table
create table if not exists public.works (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  title text not null,
  description text,
  type text not null,
  date text,
  content_url text,
  image_url text
);

alter table public.works add column if not exists tags text[] default '{}';
alter table public.works add column if not exists featured boolean default false;
alter table public.works add column if not exists status text default 'published';
alter table public.works add column if not exists views integer default 0;

-- 2. Create 'guestbook' table
create table if not exists public.guestbook (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  name text not null,
  message text not null,
  visitor_id uuid not null,
  is_approved boolean default false
);

-- 3. Create 'portal_items' table
create table if not exists public.portal_items (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  label text not null,
  url text not null,
  description text,
  icon text not null,
  category text default 'SOCIAL',
  is_visible boolean default true,
  sort_order integer default 0
);

-- 4. Create 'profile' table
create table if not exists public.profile (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  full_name text default 'Luki',
  bio text,
  avatar_url text,
  status text default 'Online',
  socials jsonb default '{}'::jsonb,
  location text,
  email text
);

-- Ensure default profile exists
insert into public.profile (id, full_name, bio, status)
select 1, 'Luki', 'Welcome to the void.', 'Online'
where not exists (select 1 from public.profile);

-- 5. Create 'playlist' table
create table if not exists public.playlist (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  youtube_id text not null,
  title text not null,
  artist text not null,
  sort_order integer default 0,
  lyrics_content text
);

-- 6. Enable RLS
alter table public.works enable row level security;
alter table public.guestbook enable row level security;
alter table public.portal_items enable row level security;
alter table public.profile enable row level security;
alter table public.playlist enable row level security;

-- 7. Policies (Public Read, Admin Write)

-- Drop potentially insecure old policies
drop policy if exists "Enable all access for works management" on public.works;
drop policy if exists "Enable all access for guestbook management" on public.guestbook;
drop policy if exists "Enable all access for anon key" on public.works;

-- Works
create policy "Public works are viewable" on public.works for select using ( status = 'published' );
create policy "Admins can manage works" on public.works for all to authenticated using ( true ) with check ( true );

-- Guestbook
create policy "Anyone can sign guestbook" on public.guestbook for insert with check ( true );
create policy "Public guestbook is viewable" on public.guestbook for select using ( is_approved = true );
create policy "Admins can manage guestbook" on public.guestbook for all to authenticated using ( true ) with check ( true );

-- Portal
create policy "Public portal items are viewable" on public.portal_items for select using ( is_visible = true );
create policy "Admins can manage portal" on public.portal_items for all to authenticated using ( true ) with check ( true );

-- Profile
create policy "Public profile is viewable" on public.profile for select using ( true );
create policy "Admins can manage profile" on public.profile for all to authenticated using ( true ) with check ( true );

-- Playlist
create policy "Public playlist is viewable" on public.playlist for select using ( true );
create policy "Admins can manage playlist" on public.playlist for all to authenticated using ( true ) with check ( true );
```

## 3. Admin Access (New Secure Method)

The admin system has been upgraded to use **Supabase Auth**.

1.  **Create Admin User:**
    *   Go to **Authentication > Users** in Supabase dashboard.
    *   Click **Add User**.
    *   Enter your desired email and password.
    *   (Optional) Disable "Email Confirmations" in Auth Settings if you want to login immediately without verifying email.

2.  **Login:**
    *   On the site, press `Ctrl + Shift + L`.
    *   Type: `login <email> <password>`
    *   Example: `login admin@luki.os mysecretpassword`

## 4. Admin Features

The new Admin Panel serves as a hub for managing all aspects of the site:

*   **Vault:** Advanced management of Works (Essays, Art, etc.) with support for Tags, Status (Draft/Published), and Views.
*   **Portal:** Add/Remove social links and external resources dynamically.
*   **Profile:** Update your bio, avatar, status, and personal info without touching code.
*   **Playlist:** Manage the music playlist and add timed lyrics.
*   **Guestbook:** Moderate messages.
