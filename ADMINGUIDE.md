# Admin Guide & Setup

## 1. Supabase Setup

To enable the backend features (Works, Guestbook), you need a Supabase project.

1.  **Create a Project:** Go to [database.new](https://database.new) and create a new project.
2.  **Get Credentials:** Go to **Project Settings > API**.
    *   Copy the `Project URL`.
    *   Copy the `anon` `public` key.
3.  **Update Environment:**
    *   Open the `.env` file in the root directory.
    *   Paste your URL and Key:
        ```env
        PUBLIC_SUPABASE_URL=your-project-url
        PUBLIC_SUPABASE_ANON_KEY=your-anon-key
        ```

## 2. Database Schema

Run the following SQL in the **SQL Editor** of your Supabase dashboard to create the necessary tables:

```sql
-- 1. Create the 'works' table for your portfolio items
create table public.works (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  title text not null,
  description text,
  type text not null check (type in ('ESSAY', 'SKETCH', 'PROJECT', 'MUSIC')),
  date text, -- e.g. "2024.01"
  content_url text, -- optional link to external content
  image_url text -- optional cover image
);

-- 2. Create the 'guestbook' table
create table public.guestbook (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  name text not null,
  message text not null,
  visitor_id uuid not null, -- Unique ID stored in user's browser to prevent identity spoofing
  is_approved boolean default false -- Messages are hidden until approved
);

-- 3. Enable Row Level Security (RLS)
alter table public.works enable row level security;
alter table public.guestbook enable row level security;

-- 4. Create Policies (Open for now, but you can restrict writes to authenticated users later)
-- Allow anyone to read works
create policy "Public works are viewable by everyone."
  on public.works for select
  using ( true );

-- Allow anyone to insert guestbook entries
create policy "Anyone can sign guestbook."
  on public.guestbook for insert
  with check ( true );

-- Allow anyone to read APPROVED guestbook entries
create policy "Public guestbook entries are viewable by everyone."
  on public.guestbook for select
  using ( is_approved = true );

-- Allow FULL ACCESS (Select, Update, Delete) to everything if you have the anon key (Client-side Admin)
-- Ideally, you'd use Supabase Auth, but for this portfolio, we are using client-side Admin Logic.
-- Since RLS is enabled, we need a policy to allow the Admin Panel to work.
-- WARNING: This policy allows ANYONE with the anon key to edit if they know how to make the request.
-- For a personal portfolio, this is often acceptable if the project URL isn't widely publicized,
-- but strictly speaking, you should use Supabase Auth for the Admin Panel.
-- For now, we will add a policy that allows all operations for simplicity, relying on the UI 'password'.
create policy "Enable all access for anon key"
  on public.works for all
  using ( true )
  with check ( true );

create policy "Enable all access for guestbook management"
  on public.guestbook for all
  using ( true )
  with check ( true );
```

## 3. Admin Terminal Access

The site features a hidden Admin Terminal.

*   **Trigger:** Press `Ctrl + Shift + L` anywhere on the site.
*   **Login:** Type `login <password>` to unlock Admin Mode.
*   **Default Password Hash:** The system uses a SHA-256 hash to verify the password.
    *   The default password is: `admin` (Hash: `8c6976e5b5410415bde908bd4dee15dfb167a9c873fc4bb8a81f6f2ab448a918`)
    *   **To Change the Password:**
        1.  Go to an online SHA-256 generator (e.g., [xorbin.com/tools/sha256-hash-calculator](https://xorbin.com/tools/sha256-hash-calculator)).
        2.  Enter your desired password.
        3.  Copy the hash.
        4.  Open `src/lib/components/TerminalAuth.svelte`.
        5.  Replace the `ADMIN_HASH` constant with your new hash.

## 4. Features

*   **Vault Management:** Once logged in, an "Admin Panel" window will appear. Use it to Add/Edit/Delete works.
*   **Guestbook Moderation:** The Admin Panel has a "Guestbook" tab. New messages appear here first. Click "Approve" to make them visible on the public site.
