# Deployment Guide: Vercel & Supabase

This guide outlines how to deploy the "Thinking Space" SvelteKit app to Vercel and connect it to a Supabase backend.

## 1. Prerequisites

*   A [GitHub](https://github.com/) account.
*   A [Vercel](https://vercel.com/) account.
*   A [Supabase](https://supabase.com/) account.

## 2. Supabase Setup

1.  **Create a Project:**
    *   Log in to Supabase and create a new project.
    *   Give it a name and set a database password.

2.  **Create the Database Table:**
    *   Go to the **SQL Editor** in the left sidebar.
    *   Run the following SQL query to create the `works` table:

    ```sql
    create table public.works (
      id bigint generated by default as identity not null,
      created_at timestamp with time zone not null default now(),
      title text null,
      description text null,
      type text null,
      date text null,
      color text null,
      constraint works_pkey primary key (id)
    );
    ```

3.  **Get API Credentials:**
    *   Go to **Project Settings** (gear icon) -> **API**.
    *   Copy the **Project URL** (`PUBLIC_SUPABASE_URL`).
    *   Copy the **anon public** key (`PUBLIC_SUPABASE_ANON_KEY`).

## 3. Vercel Deployment

1.  **Push to GitHub:**
    *   Ensure your project is pushed to a GitHub repository.

2.  **Import to Vercel:**
    *   Log in to Vercel and click **"Add New..."** -> **"Project"**.
    *   Select your GitHub repository.

3.  **Configure Project:**
    *   Framework Preset: **SvelteKit** (should be detected automatically).
    *   **Environment Variables:** Add the Supabase keys you copied earlier:
        *   `PUBLIC_SUPABASE_URL`: (Paste your Project URL)
        *   `PUBLIC_SUPABASE_ANON_KEY`: (Paste your anon public key)

4.  **Deploy:**
    *   Click **"Deploy"**.
    *   Wait for the build to finish. Once done, your site is live!

## 4. Using Ghost Admin Mode

1.  Open your deployed site.
2.  Open the **Vault** (Top Right Corner).
3.  Press **`Shift + L`** on your keyboard.
4.  The **[UPLOAD]** button will appear in the top right of the Vault window.
5.  Click it to add new entries to your Supabase database.
